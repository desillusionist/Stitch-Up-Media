## 1.0.10

**The RESOLUTION row reads `CUSTOM` while an exact size is in force.** A job with a size typed into EXACT SIZE exported at that size while the row above still named `1080P` — a figure the encoder would not use. That row now says what is actually happening.

`CUSTOM` is a readout, not a choice: the size fields beneath it are where the size is set. Choosing a named resolution clears them (the way back), and the row's own reset now clears both the name and the exact size.

Aspect-ratio and MS buttons write an exact size too, so the row reads `CUSTOM` there as well — same rule, same fact.

**Installing:** drag the app to Applications, then clear the quarantine flag —
`xattr -dr com.apple.quarantine "/Applications/Stitch Up Media.app"`. The build is unsigned and not notarised. **Check for Updates…** in the app menu will offer this release from any copy on 1.0.7 or later.
